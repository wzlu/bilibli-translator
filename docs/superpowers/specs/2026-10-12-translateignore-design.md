# md2zh:`.translateignore` 忽略列表设计文档

- 日期:2026-10-12
- 状态:已批准(设计分节经用户确认)
- 关联:与 ds-translator 共享同一份 `.translateignore`(硬链接),匹配语义与之对齐

## 1. 背景与目标

`--filelist` 批量翻译时,提供一个"无需翻译的文件清单"机制:位于忽略列表中的文件直接略过,不调用翻译 API、不生成译文。忽略列表文件为 `.translateignore`,当前工作目录存在时自动读取,格式为每行一条规则(精确路径或通配模式),与 ds-translator 的既有语义对齐。

## 2. 范围与非目标

- 生效范围:仅 `--filelist` 批量模式;单文件模式与 stdin 模式不读取忽略列表。
- 无新 CLI 选项:仅按当前工作目录自动发现 `.translateignore`。
- 非目标:不做 gitignore 完整语义(逐目录继承、`!` 反排除),不做 `append_to_ignore` 等写入功能(ds-translator 的写功能不在 md2zh 范围)。

## 3. 澄清决策(与用户确认)

| 决策点 | 结论 |
|---|---|
| 发现机制 | 仅当前工作目录自动发现,不加新选项 |
| 通配符 | 支持(真实文件中混有精确路径与 `**`/`*` 模式) |
| 匹配实现 | 统一正则翻译(单通道),与 ds-translator 对 `**` 模式行为一致 |
| 呈现方式 | 独立「忽略」统计类别,汇总为 成功/跳过/忽略/失败 |

## 4. 方案选型

- **方案 A(选定):统一正则翻译**。自研约 15 行段翻译:`**` → `.*`、段内 `*`/`?` 不跨分隔符、字符类保留、相对模式从右侧匹配、大小写不敏感。与 ds-translator 的 `**` 模式行为一致;对无 `**` 的相对模式存在轻微段边界过匹配,记为已知限制。
- 方案 B(双通道照抄 ds-translator):无 `**` 走 `PurePath.match`、含 `**` 走 fnmatch 正则。行为完全一致但两套逻辑并存、依赖 pathlib 版本细节(Python < 3.12 的 match 不支持 `**`),不采用。
- 方案 C(简单 fnmatch):`*` 跨路径分隔符,段边界过匹配明显(如 `**\i18n\*` 会命中 `xi18n` 目录),不采用。

## 5. 解析规则(新模块 src/md2zh/ignore.py)

纯模块,与 markdown.py / checks.py 同层:

- 逐行去空白;空行与 `#` 开头注释行跳过(与 parse_filelist 一致);
- 编码:utf-8-sig(兼容 BOM)→ 失败回退 GBK(与 ds-translator 对齐)→ 仍失败:stderr 警告 `md2zh: 警告: 无法读取忽略文件 {path},不使用忽略规则`,视为空表,翻译继续;
- 行分类:含 `*` / `?` / 成对 `[]` → 通配模式;否则 → 精确路径;
- 以 `\` 或 `/` 结尾的行先追加 `*` 再分类(段内通配,目录直接子文件语义;裸目录行如 `reports/` 同样生效);

接口:

- `load_ignore(path: str) -> IgnoreMatcher` — 文件不存在返回空匹配器(静默);
- `IgnoreMatcher.is_ignored(path: str) -> bool` — 命中任一规则返回 True。

## 6. 匹配语义

- 归一化:`normcase(abspath(normpath(p)))` 后将 `\` 统一为 `/`(小写、单分隔符形态);路径与模式统一应用;
- 精确条目:归一化后集合 O(1) 相等比较(相对条目按 CWD 解析);
- 通配条目:编译为锚定正则(re.fullmatch),预编译一次、全批复用(53 KB 文件约 1500 条,无重复编译开销):
  - `**` → `.*`(跨分隔符递归);
  - 段内 `*` → `[^/]*`、`?` → `[^/]`(不跨分隔符);
  - `[...]` 字符类保留;其余字符 re.escape;
  - 相对模式(不以盘符、`\`、`/` 开头)前缀 `.*` 实现从右侧匹配;绝对模式不前缀。

## 7. CLI 接线与统计

- `cli.main` filelist 分支:加载当前工作目录 `.translateignore` 得到 matcher,传入 `run_batch`;
- `run_batch` 循环内先查忽略(优先于扩展名与存在性检查——忽略列表中的过期路径同样静默略过,与 ds-translator 预过滤顺序一致);
  - 命中:stderr `md2zh: 忽略 p: 命中忽略列表`,ignored += 1,continue;
- `--force` 不覆盖忽略(忽略优先);
- 汇总:stderr `md2zh: 汇总: 成功 X,跳过 Y,忽略 Z,失败 W`;
- 退出码契约不变:存在失败 → 1;全部成功/跳过/忽略 → 0;
- `translate_file`、`run_single`、`run_stdin` 不改动。

## 8. 错误处理

| 场景 | 行为 |
|---|---|
| 忽略文件不存在 | 空表,无输出 |
| 解码失败(UTF-8 与 GBK 均失败) | stderr 警告 + 空表,退出码不受影响 |
| 忽略命中 | 计入忽略数,不算失败 |

## 11. 已知限制

- 无 `**` 的相对模式可能轻微过匹配段边界(如模式 `docs/a*.md` 会命中 `xdocs/a.md`),损害有界:最多多跳过可在 stderr 审计的文件;
- 含字面 `*`/`?` 的路径会被当作通配模式处理(与 ds-translator 一致,可用 `[...]` 转义);
- 不支持 gitignore 的 `!` 反排除与逐目录继承;字符类内 `!` 取反同样不支持(按 Python re 语义解析);
- 目录模式按"直接子文件"语义实现(追加段内 `*`);ds-translator 追加 `**` 实际为递归匹配,两者略有差异。
